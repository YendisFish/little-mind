# Little Mind
Little mind is a unique application that opens
a new way to interact with LLMs and your own
mind. Try it out and see how Little Mind can
open up a new paradigm of interactions with LLMs
and organization of your thoughts.

### Dependencies
Right now Little Mind requires Bun and
Cargo in order to build. The default config
expects ollama to be running however, it can
connect to any OpenAI compatible API.

Right now Little Mind also has a hardcoded
requirement for the model ``batiai/gemma4-26b:q3``
from ollama.
